1. INTRODUCTION                                        *rust-doc-introduction*

rust-doc.nvim indexes the HTML generated by `cargo doc` (your crate and its
dependencies) and the standard library docs installed by rustup, and opens the
matching page in a browser.  It is a Lua port of rhysd/rust-doc.vim.

The Cargo project is found by walking up from the current buffer's directory
to the outermost `Cargo.toml` containing `[workspace]`, or otherwise the
nearest `Cargo.toml`.  Project docs take priority over the standard library.
If `<target>/doc` does not exist, `cargo doc` is run asynchronously first
(see |rust-doc-auto_generate|).  The target directory honours
$CARGO_TARGET_DIR and `cargo metadata`.

==============================================================================
2. REQUIREMENTS                                        *rust-doc-requirements*

- Neovim 0.10 or newer.
- `cargo` for project docs.
- `rustup` with the `rust-docs` component for std docs: >
    rustup component add rust-docs
<  Or set |rust-doc-std_doc_dir|.

==============================================================================
3. COMMANDS                                                *rust-doc-commands*

                                                                    *:RustDoc*
:RustDoc {crate-or-module} [{item}]
    Open the exact crate or module, or an item inside it.  Both arguments
    complete with <Tab>.  Examples: >
        :RustDoc rand
        :RustDoc rand::distributions
        :RustDoc rand Rng
        :RustDoc std::vec
<   When nothing matches and |rust-doc-list_on_miss| is set, a picker with
    the available modules (or the module's items) is shown.

                                                               *:RustDocFuzzy*
:RustDocFuzzy {identifier}
    Search every module and item for {identifier} as a whole word of the
    path (`Rng` matches `rand::Rng`, not `rand::RngCore`).  An exact full-path
    match, or a single candidate, opens immediately; otherwise a
    |vim.ui.select()| list is shown.  Example: >
        :RustDocFuzzy distributions
<
                                                              *:RustDocModule*
:RustDocModule {name}
    Like |:RustDocFuzzy| but only crate/module names are searched.  Completes
    module names.  Example: >
        :RustDocModule std::io
<
                                                                *:RustDocPick*
:RustDocPick [modules]
    List every documented page with |vim.ui.select()|.  With the `modules`
    argument only modules and crates are listed, which is much faster for
    large dependency trees.  See |rust-doc-pickers|.

                                                            *:RustDocGenerate*
:RustDocGenerate
    Run `cargo doc` (plus |rust-doc-cargo_doc_args|) in the current project,
    asynchronously.  Use it after dependencies change.

==============================================================================
4. MAPPINGS                                                *rust-doc-mappings*

                                                      *<Plug>(rust-doc-search)*
<Plug>(rust-doc-search)
    Normal mode: |:RustDocFuzzy| on the |<cword>|.  Visual mode: on the
    selected text.  Example: >
        vim.keymap.set({ 'n', 'x' }, '<leader>rd', '<Plug>(rust-doc-search)')
<
                                                              *rust-doc-map_K*
With `map_K = true` in |rust-doc-configuration|, `K` is mapped buffer-locally
in Rust buffers to the same action.  It is disabled by default because it
replaces the LSP hover on `K`.

==============================================================================
5. CONFIGURATION                                      *rust-doc-configuration*

Call `require('rust-doc').setup({opts})`.  Defaults: >lua
    {
      open_cmd = nil,
      vim_open_cmd = nil,
      std_doc_dir = nil,
      search_std = true,
      list_on_miss = true,
      auto_generate = true,
      cargo_doc_args = {},
      map_K = false,
    }
<
                                                              *rust-doc-open_cmd*
open_cmd ~
    A string, list of strings, or `function(url)` used to open a `file://`
    URL.  For strings and lists the URL is appended as the last argument and
    the command is spawned detached. >lua
        open_cmd = { 'firefox', '--new-tab' }
        open_cmd = function(url) vim.system({ 'w3m', url }) end
<
                                                          *rust-doc-vim_open_cmd*
vim_open_cmd ~
    An Ex command to open the URL inside Neovim (for example `'edit'` with a
    text-browser plugin).  Takes precedence over `open_cmd`.

    If neither is set, |vim.ui.open()| is used (xdg-open, open, or the
    Windows shell handler).

                                                           *rust-doc-std_doc_dir*
std_doc_dir ~
    Directory of standard library docs (the one containing `std/`).  When
    unset the plugin asks `rustup doc --path`, then falls back to
    `$(rustc --print sysroot)/share/doc/rust/html`.  Only `std`, `core`,
    `alloc`, `proc_macro` and `test` are indexed.

                                                           *rust-doc-search_std*
search_std ~
    Include standard library docs.  Default `true`.

                                                         *rust-doc-list_on_miss*
list_on_miss ~
    Show a picker of candidates when |:RustDoc| finds nothing.  Replaces
    rust-doc.vim's `g:rust_doc#do_not_ask_for_module_list` (inverted).
    Default `true`.

                                                        *rust-doc-auto_generate*
auto_generate ~
    Run `cargo doc` automatically when the project has no `doc` directory.
    When `false`, run |:RustDocGenerate| yourself.  Default `true`.

                                                       *rust-doc-cargo_doc_args*
cargo_doc_args ~
    Extra arguments for `cargo doc`, e.g. `{ '--no-deps' }`.

==============================================================================
6. LUA API                                                      *rust-doc-api*

>lua
    local rd = require('rust-doc')
    rd.open(module, item?)      -- like :RustDoc
    rd.search(query)            -- like :RustDocFuzzy
    rd.search_module(query)     -- like :RustDocModule
    rd.pick(modules_only?)      -- like :RustDocPick
    rd.generate_current()       -- like :RustDocGenerate
<
==============================================================================
7. PICKERS                                                   *rust-doc-pickers*

|:RustDocPick| and ambiguous searches call |vim.ui.select()|.  Plugins that
override it give you a fuzzy finder over all docs, e.g. telescope-ui-select,
fzf-lua (`register_ui_select`), snacks.picker, mini.pick or dressing.nvim.
This replaces the unite.vim and denite.nvim sources of rust-doc.vim.
